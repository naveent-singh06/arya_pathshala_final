# ARYA PATHSHALA - Phase 1 setup (AI Tutor)

What you need to configure yourself. No secret values belong in this repository.

## 1. Firebase (your existing project)
1. **Authentication**: Google sign-in stays as it is. Add your Vercel domain under
   *Authentication -> Settings -> Authorized domains*, or Google sign-in will fail on the live site.
2. **Firestore**: *Build -> Firestore Database -> Create database*. Do not enable Storage yet (Phase 2).
3. **Rules**: publish `firestore.rules` (Firestore -> Rules, or `firebase deploy --only firestore:rules`).
   Students can only read/write their own chats; the `tutorUsage` counters are server-only.
4. **Service account** (server only): *Project settings -> Service accounts -> Generate new private key*.
   Paste the whole JSON (or its base64) into the `FIREBASE_SERVICE_ACCOUNT_JSON` environment variable.
   Never commit this file.

## 2. AI provider
Any OpenAI-compatible chat-completions API. Default is Groq with `llama-3.3-70b-versatile`.
Create a key at https://console.groq.com and set `LLM_API_KEY`.
To switch provider or model, change only `LLM_BASE_URL` / `LLM_MODEL` / `LLM_API_KEY`.
Check the provider's model list from time to time; providers retire models.

## 3. Vercel environment variables
Add every name from `.env.example` in *Project Settings -> Environment Variables*:
the `REACT_APP_FIREBASE_*` values (public by design) and the server-only values
(`LLM_*`, `TUTOR_*`, `FIREBASE_SERVICE_ACCOUNT_JSON`). `vercel.json` already routes the website
to `index.html` and allows `/api/tutor` up to 60 seconds.

## 4. Running locally
`npm start` only serves the website. To run the website **and** `/api/tutor` together use
`npx vercel dev` with a `.env.local` file made from `.env.example`.

## 5. Tests
- `npm run test:api` - server API tests (no network or keys needed).
- `CI=true npm test` - React tests.
- `npm run build` - production build.

## Known limits (Phase 1)
- The Firestore security rules have been reviewed by hand but not run in the Firebase emulator.
- The AI answers are generated by a language model and can be wrong; the tutor says so and asks
  students to verify important answers. Image/PDF questions, voice and study-material search (RAG)
  are planned for later phases and are not in this release.
- Usage limits are per student: `TUTOR_RATE_PER_MINUTE` (default 8) and `TUTOR_DAILY_LIMIT` (default 100).
